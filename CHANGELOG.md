## [1.0.0] - 2024-12-06

### Added
- Initial release of Transformers Cards for Home Assistant
- 11 card types with Transformers/Teletraan-I inspired design:
  - Status Card - Display multiple entity states with status indicators
  - Sensor Card - Single sensor visualization with progress bar
  - Button Card - Interactive control buttons with tap actions
  - Text Card - Terminal-style text display with dynamic content
  - Gauge Card - Circular gauge with severity thresholds
  - Clock Card - Live time display with multiple formats
  - Glance Card - Multi-entity compact overview
  - Light Card - Light control with brightness slider
  - Picture Card - Image/camera display with auto-refresh
  - Weather Card - Weather information with forecast
  - Alarm Card - Alarm control with numeric keypad
- Transformers Movie font integration
- Autobot (red/blue) and Decepticon (purple) color themes
- Angular, tech-inspired design with grid patterns
- HACS compatibility
- Full TypeScript/Lit implementation
- Comprehensive documentation and examples

### Features
- Dynamic content with template variables
- State-based text display
- Tap action support for navigation and services
- Camera auto-refresh capability
- Severity-based color coding
- Responsive design for mobile and desktop
- CRT-style visual effects
- Tech panel aesthetics
