# Transformers Font

This directory contains the Transformers Movie font used in the card designs.

## Font Information

- **Font Name**: Transformers Movie
- **File**: TransformersMovie-y9Ad.ttf
- **License**: Freeware, Non-Commercial Use
- **Source**: https://www.fontspace.com/transformers-movie-font-f34560

## License

The Transformers Movie font is licensed for free non-commercial use. See the original source for full licensing details.

## Usage

The font is automatically loaded through the card's CSS and can be used by setting the appropriate CSS custom property in your theme or card configuration.
